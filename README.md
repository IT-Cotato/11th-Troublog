# 📖 프로젝트 소개

> [!IMPORTANT]
> **Troublog**는 개발자들이 프로젝트 진행 중 발생하는 문제와 해결 과정을 체계적으로 기록, 관리하고 이를 이력서 및 포트폴리오에 활용할 수 있도록 지원하는 플랫폼입니다.

## 🎯 프로젝트 목적

개발자들이 트러블슈팅 경험을 통해 성장하고, 유사한 문제 발생 시 빠르게 대처할 수 있는 환경을 제공하는 서비스입니다.

### 네이밍 의미

**『트러블로그 (Troublog)』**는 두 가지 의미를 담고 있습니다:

1. **Trouble + log**
   - '버그나 트러블슈팅 기록'이라는 서비스의 핵심 목적을 명확히 전달
   - 기술적인 뉘앙스를 효과적으로 담음

2. **Trouble + blog**
   - 기록을 블로그 형태로 남기고 관리
   - 자연스럽게 포트폴리오화할 수 있다는 장점

# 📐 Ground Rules

> [!NOTE]
> 팀의 원활한 협업을 위한 기본 규칙입니다.

## 🤝 커뮤니케이션

- **존댓말 사용**: 공지방 및 회의 시 존댓말 사용 (파트끼리는 자유)
- **공지 확인**: 카톡 공지를 읽으면 꼭 체크(✅) 표시하기
- **적극적인 의견 공유**: 회의 때 의견 많이 내기

## ⏰ 시간 약속

- **지각 금지**: 늦을 것 같으면 10분 전까지 꼭 말하기
- **패널티**: 가장 늦게 온 사람이 가장 일찍 온 사람에게 커피 ☕

## 📝 문서화

- **노션 활용**: 자료 올리면 꼭 읽어보고 댓글 남기기 (`.` 도 가능)
- **즉시 공유**: 문제, 질문, 불만, 건의사항이 있다면 단톡방에 바로 이야기하기

# 📦 통합 모듈 저장소

> [!NOTE]
> Troublog 프로젝트는 Frontend와 Backend를 **Git 서브모듈**로 통합 관리하는 구조를 사용합니다.
> 이를 통해 전체 프로젝트를 한 번에 관리하고, Dependabot을 활용하여 서브모듈을 자동으로 최신 상태로 유지합니다.

## 🏗️ 저장소 구조

통합 저장소는 다음과 같은 구조로 구성됩니다:

```
11th-Troublog/                    # 통합 저장소 (메인)
├── .github/
│   └── dependabot.yml           # Dependabot 자동 업데이트 설정
├── .gitmodules                  # 서브모듈 설정 파일
├── backend/                     # Backend 서브모듈
│   └── (11th-Troublog-BE)
├── frontend/                    # Frontend 서브모듈
│   └── (11th-TroubleLog-FE)
└── README.md                    # 통합 저장소 README
```
